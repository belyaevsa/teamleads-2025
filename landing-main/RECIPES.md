# Рецепты агентов – как добавить свой

Участники сообщества «Тимлид не кодит» складывают сюда промпты, скиллы и харнессы, которые реально используют в работе. Не демки, а то, что запускается в понедельник.

Каждый рецепт – отдельный `.md` файл в папке `landing-main/content/agents/`. Файл попадает на сайт после мержа Pull Request.

## Что считается рецептом

Годится: промпт для разбора инцидента, скилл для Claude Code, субагент для ревью, харнесс из нескольких агентов, конфиг MCP-сервера. Все, что вы уже запускали больше одного раза.

Не годится: идея без текста промпта, скриншот чата, пересказ статьи. Рецепт должен копироваться и запускаться.

## Вариант ноль: просто напишите в чат

Не хотите возиться с GitHub – не возитесь. Скиньте промпт в [чат сообщества](https://telegram.me/teamleads_kz) и напишите «в рецепты». Мы оформим страницу и поставим вас автором. Правки потом принимаются так же, через чат.

Это не запасной путь для ленивых. Это основной путь. Pull Request ниже – для тех, кому приятнее самому.

## Пошаговая инструкция (три варианта, кому какой ближе)

### Веб-интерфейс

1. Откройте в браузере папку [landing-main/content/agents](https://github.com/belyaevsa/teamleads-2025/tree/master/landing-main/content/agents)
2. Нажмите кнопку Add file. Предложат сделать форк – соглашайтесь.
3. **Назовите файл** латиницей через дефис, например `mock-interview.md`
4. Вставьте содержимое шаблона [landing-main/agent-template.md](https://github.com/belyaevsa/teamleads-2025/blob/master/landing-main/agent-template.md)
5. **Заполните frontmatter** – все поля описаны в шаблоне
6. **Напишите тело рецепта.** Промпт целиком, в блоке кода. Плюс раздел «Что проверять за агентом» – без него рецепт не примут.
7. Нажмите `Commit changes`, выберите создать новую ветку, соглашайтесь на Pull Request

### Онлайн-редактор

1. Откройте папку [landing-main/content/agents](https://github.com/belyaevsa/teamleads-2025/tree/master/landing-main/content/agents)
2. Нажмите `.` (да, точку)
3. Вы в браузерном VSCode. Дальше как обычно.

### Форк репозитория

1. **Форкните** – https://github.com/belyaevsa/teamleads-2025
2. **Скопируйте шаблон** `landing-main/agent-template.md` в `landing-main/content/agents/`
3. **Заполните** и отправьте Pull Request в ветку `master`

## Что мы просим соблюдать

**Промпт целиком.** «Я попросил его сделать ревью» – не рецепт. Текст в блоке кода – рецепт.

**Раздел «Что проверять за агентом» обязателен.** Где он врет, что придумывает, на чем его нельзя оставлять без присмотра. Сообщество к автогенерации относится скептически – и правильно делает. Рецепт без этого раздела мы попросим дописать.

**Никаких секретов.** Ключи, внутренние URL, имена клиентов, куски приватного кода – вычищайте перед коммитом. История git помнит все.

**Свой опыт, а не пересказ.** Если рецепт взят у кого-то, поставьте `sourceUrl` на оригинал.

**Устаревший рецепт лучше отсутствующего.** Поле `tested` показывает модель и месяц проверки. Промпт, который отлично работал полгода назад, все равно полезен: видно, что человек пробовал и к чему пришел. Не держите рецепт в заметках из-за того, что он «уже не самый свежий».

## Что происходит после мержа

Страница появляется на [teamleads.kz/agents/](https://teamleads.kz/agents/), попадает в поиск по сайту (`grep` в терминале), в `llms.txt` и открывается командой `cat agents/<имя>` в [браузерном терминале](https://teamleads.kz/shell/). Кнопка «Скопировать рецепт» отдает исходный markdown целиком.

Если рецепт автоматизирует шаблон из [операционки](https://teamleads.kz/toolkit/), укажите его имя в поле `basedOn` – страницы свяжутся ссылками.
